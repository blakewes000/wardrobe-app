# Project: Wardrobe Outfit Builder

## About the person
- Absolute beginner. This is their first coding project ever.
- Uses Windows. Will test on both a Windows computer and a phone.
- Explain everything in simple, short sentences. State the obvious. Define any technical word the first time you use it.
- Tell them exactly what to click or type, step by step.

## About the app
A personal wardrobe app. See SPEC.md for full details. One user only: no login, no accounts, no payments, no server database.

## Tech rules (keep it simple)
- Use plain HTML, CSS, and JavaScript only. No frameworks, no build tools, no npm unless absolutely necessary.
- Keep the number of files small and the code easy to read. Add short comments explaining what each part does.
- Save all data in the browser (IndexedDB for photos, localStorage for small settings).
- Weather comes from the free Open-Meteo service (no API key).
- Design for phone screens first, then make it work on computers.
- Never ask the user to paste secret keys into the code.

## How to work
- Before coding anything new, give a short plan in plain English and wait for approval.
- Build ONE small step at a time (follow the build order in SPEC.md). Do not jump ahead.
- After each step, tell the user how to open the app and exactly what they should see.
- Explain what you changed in 2-3 simple sentences.
- Use Git: after each working step, make a commit with a clear message.
- If something breaks, explain what went wrong in plain English, then fix it.
- Ask before deleting any file.
